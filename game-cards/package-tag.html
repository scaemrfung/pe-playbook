19. Package Tag

Tag & chase

When: December · Slot: 16-25

Tagged player sits as a package (hands in a bow). A classmate opens them to rejoin.

Equipment: Pool noodles

Set-up: Taggers with noodles.

How we play

  1. Tag = sit criss-cross, hands in a bow.
  2. A classmate opens the package to free them.
  3. Freeze on the whistle.
Grades 1–2. Standing package.
Grades 3–4. More taggers.
Grades 5–6. No noodles.

Safety. No elimination. Freeze on the whistle. Soft tags - never the head.
